# محطة مياه الفرات

نظام إدارة احترافي قابل للتعديل من داخل البرنامج.

## المميزات
- لوحة تحكم رئيسية
- إدارة الموظفين
- تسجيل السحوبات
- حضور وغياب
- تقارير موظفين
- سحوبات خاصة
- إعدادات الشركة
- إدارة الأقسام داخل التطبيق
- نسخة احتياطية واستعادة
- حفظ البيانات في المتصفح عبر localStorage

## التشغيل
1. افتح الملف `index.html` في المتصفح، أو استخدم خادم ثابت بسيط.
2. إذا كنت تستخدم VS Code، يمكنك تشغيل Live Server.

## الهيكل
- `index.html`
- `css/styles.css`
- `js/app.js`

## ملاحظة
هذا المشروع مصمم ليعمل كنسخة احترافية وقابلة للتوسع في المتصفح، مع إدارة بيانات داخل التطبيق عبر الإعدادات. إذا رغبت، يمكن توسيع هذا المشروع لاحقًا إلى نسخة كاملة تدعم قاعدة بيانات حقيقية ومستخدمي النظام.
